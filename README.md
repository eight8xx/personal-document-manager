# 个人文档管理

本地优先的 Windows 文档管理工具。把散落在下载目录、桌面和各个文件夹里的文件导入受管理的**资料库**，再用集合、标签、文档日期和全文检索把它们找回来。

源文件不会被修改；导入后的**资料库副本**是应用持续管理的权威版本。

## 安装

安装包位于 `release/个人文档管理-Setup-0.1.0.exe`。双击后按向导完成安装，无需管理员权限，也无需另装运行环境。

安装完成后可从桌面快捷方式或开始菜单中的“个人文档管理”启动。

## 便携版

`release/个人文档管理-Portable.exe` 可直接双击运行，无需安装。便携版与安装版使用相同的本地数据和最近资料库记录。便携版不包含 WebView2 安装组件；目标电脑缺少 WebView2 Runtime 时，请先运行安装版。

## 首次运行

Windows 可能显示“Windows 已保护你的电脑”，因为当前安装包尚未进行代码签名。选择“更多信息”，确认应用名称和来源后再选择“仍要运行”。

应用适用于 Windows 10/11 64 位系统。安装包内置 WebView2 离线安装组件，目标电脑无需联网下载运行环境；代价是安装包体积较大，本版约为 209 MB。

首次启动时选择一个空目录或已有资料库目录作为资料库位置。之后可从设置里切换最近使用过的资料库。

## 支持的文档格式

| 格式 | 导入 | 正文搜索 | 应用内预览 |
| --- | --- | --- | --- |
| PDF | 是 | 是 | 按页渲染（首页生成缩略图） |
| DOCX | 是 | 是 | 版式只读预览 |
| PPTX | 是 | 是 | 幻灯片只读预览（首页缩略图） |
| XLSX | 是 | 是（单元格文字） | 按工作表与行列分页浏览 |
| CSV | 是 | 是（单元格文字） | 按行列分页浏览 |
| TXT / Markdown | 是 | 是 | 纯文本 / 安全子集渲染 |
| JPG / PNG | 是 | 否 | 图片预览，网格生成缩略图 |

表格与 Office 文档在应用内只读呈现：不执行宏、脚本、嵌入对象或外部链接请求，也不会在应用内计算表格公式（只显示文件里已有的公式缓存值）。任何文档都可以用系统默认程序外部打开资料库副本。

第一版不含旧 `.ppt`、`.xls`、启用宏的 `.pptm/.xlsm` 与 `.ods`；这些格式会被明确拒绝并说明原因。

## 导入

- 用工具栏的导入按钮选择文件或文件夹，或把文件/文件夹直接拖进窗口。
- 导入时会先询问**是否应用分类规则**，并预览每项预计的集合、标签与命中的规则；可以选择按原有方式导入。
- 重复内容会暂停该文件的导入，由你决定打开已有文档、仍然单独导入或取消；同一来源内容变化时由你选择新建文档或替换已有文档。
- 批量导入逐文件处理：单个失败不影响其它文件，失败项显示阶段与原因并可以单独重试。
- 导入期间仍可浏览、搜索和预览已有文档。

## 整理

- **集合**：主要归档位置，可嵌套；收件箱是内置集合，不能被删除，删除集合时其中的文档会移回收件箱。
- **标签**：跨集合的主题标记，一份文档可以有多个。
- **分类规则**：在「设置 → 分类规则」里按文件名、文件类型、来源目录匹配，为新导入的文档自动指定集合与标签。规则按你设定的顺序匹配，第一条指定集合的命中规则决定集合；命中规则的标签会合并；未命中进入收件箱。也可以先停用规则只做试运行。
- **批量操作**：多选文档后可批量移动到集合、批量加/减标签、批量移入回收站。

## 接收目录（QQ / 微信）

在「设置 → 接收目录」里为当前资料库分别配置 QQ 和微信在本机的接收目录：

1. 应用会给出候选目录与识别依据，**由你确认或自行填写**，未确认前不会扫描或导入。
2. 首次启用时列出目录里已有的受支持文件，由你选择要导入哪些；**你没选的文件以后也不会被自动导入**，清单可以随时再次打开补选。
3. 应用运行期间会周期检查这些目录，把新保存且写入完成的受支持文件自动导入；导入结果可以在面板的「最近接收导入」里回看。
4. 应用关闭后不残留任何监视进程；关闭期间新增的文件会在下次打开该资料库时补扫导入。
5. 同一来源的文件内容被改写时，会生成待决项，由你在日志里选择**新建文档**或**替换已有文档**；未处理前不会自动导入。
6. 目录失效或权限不足时只提示重新确认，不会静默改用别的目录。

## 搜索

- 按标题、描述和提取出的正文搜索；中文和英文都支持，结果带正文匹配片段。
- 一至两个字符的短查询只匹配标题、描述与元数据（不匹配正文），这是索引方式的取舍。
- 可以按集合、标签、文件类型和文档日期组合筛选。

## 删除与恢复

删除文档只是移入回收站，可随时恢复；恢复时优先回到原集合，原集合不存在则回到收件箱。回收站不会自动清理，只有你明确执行永久删除或清空回收站时，资料库副本才会被移除。用户创建的源文件在任何情况下都不会被应用修改或删除。

## 数据位置

应用状态和最近资料库记录保存在：

`%APPDATA%\com.local.personal-document-manager`

用户创建的资料库位于用户选择的位置，文档和资料库数据不会因卸载自动删除。

资料库目录内包含：`documents/`（资料库副本）、`trash/`、`thumbnails/` 与 `.pdm/`（元数据与 SQLite 数据库）。备份资料库前请先关闭应用。

## 开发者

```
npm install
npm run dev            # Vite 前端开发服务
npm run tauri dev      # 启动桌面应用
npm test               # 前端测试（vitest，21 个文件）
npm run typecheck      # TypeScript 类型检查
cargo test --manifest-path src-tauri/Cargo.toml   # Rust 测试（202 项）
npm run package:windows                            # 构建安装包与便携版到 release/
```
