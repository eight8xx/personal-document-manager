# 第二版发布说明（v0.1.0）

本地优先的 Windows 个人文档管理工具。把散落在下载目录、桌面与各文件夹里的文件导入受管理的**资料库**，再用集合、标签、文档日期和全文检索找回来。源文件不会被修改；导入后的资料库副本是应用持续管理的权威版本。

## 本版新增

**表格文档**

- 支持导入、只读浏览、按单元格文字搜索 **CSV** 与 **XLSX**（含多工作表、共享字符串、稀疏行列与公式缓存值）。
- 预览按工作表与行列分页，一次只加载有限范围；公式不会被计算，只显示文件里已有的缓存值。
- 旧 `.xls`、`.ods`、启用宏的 `.xlsm/.xlsb`、加密与畸形工作簿会被明确拒绝并给出原因。

**接收目录自动导入（QQ / 微信）**

- 每个资料库分别配置 QQ、微信在本机的接收目录；应用给出候选目录与识别依据，**由你确认后才开始扫描**。
- 首次启用时列出目录里已有的受支持文件，由你选择导入哪些；**你没选的文件以后也不会被自动导入**，清单可随时再打开补选。
- 应用运行期间周期检查这些目录并自动导入新保存且写入完成的文件；关闭应用后不残留监视进程，关闭期间新增的文件会在下次打开资料库时补扫导入。
- 同一来源内容被改写时生成待决项，由你选择**新建文档**或**替换已有文档**。

**分类规则**

- 按文件名、类型、来源目录匹配，为新导入的文档自动指定集合与标签。
- 多次命中时按你的顺序取第一条指定集合的规则，标签合并去重；未命中进入收件箱。
- 人工批量导入前会询问是否应用规则，并分页预览每项的预计集合、标签与命中规则；规则或文件在预览后发生变化会要求你复核。

**可靠性**

- **导入期间保持可用**：批量导入改为逐项加锁，导入进行中仍可浏览、搜索和预览已有文档。
- **替换副本可恢复**：来源变化替换副本的过程中意外退出，重新打开资料库时会对账恢复为一致状态。
- **资源上限**：Office 与表格文档的压缩包解析在分配或解压前检查输入大小、单条目、压缩比与累计解压量；超限文档单项失败，不影响同批其它文件。
- **崩溃与占用恢复**：中断留下的残留被占用时不再导致资料库打不开；孤儿副本会被移到 `.recovered-orphans/`（只搬不删，附说明文件）。
- 列表与网格在万份文档下按窗口挂载，长时间滚动不会持续膨胀。

## 支持格式

| 格式 | 导入 | 正文搜索 | 应用内预览 |
| --- | --- | --- | --- |
| PDF | 是 | 是 | 按页渲染，首页生成缩略图 |
| DOCX | 是 | 是 | 版式只读预览 |
| PPTX | 是 | 是 | 幻灯片只读预览，首页缩略图 |
| XLSX | 是 | 是（单元格文字） | 按工作表与行列分页 |
| CSV | 是 | 是（单元格文字） | 按行列分页 |
| TXT / Markdown | 是 | 是 | 纯文本 / 安全子集渲染 |
| JPG / PNG | 是 | 否 | 图片预览与网格缩略图 |

Office 与表格文档在应用内只读呈现：不执行宏、脚本、嵌入对象或远程资源请求。任何文档都可以用系统默认程序外部打开资料库副本。

## 安装

- `个人文档管理-Setup-0.1.0.exe`：NSIS 安装包，无需管理员权限，内置 WebView2 离线组件（因此约 209 MB），目标电脑无需联网下载运行环境。
- `个人文档管理-Portable.exe`：便携版，双击即用；不含 WebView2 组件，目标电脑缺少 WebView2 Runtime 时请先运行安装版。

安装包尚未进行代码签名，Windows 可能提示"已保护你的电脑"，选择"更多信息 → 仍要运行"。

适用 Windows 10/11 64 位。

## 数据位置

- 应用状态与最近资料库记录：`%APPDATA%\com.local.personal-document-manager`
- 资料库位于你选择的位置，卸载不会删除资料库数据；备份前请先关闭应用。

## 验证情况

- 自动化：Rust 202 项、前端 172 项测试全部通过；一万份合成资料库的导入、索引、重启核对、搜索、筛选、外部修改、回收站闭环在 debug 配置下通过。
- 人工：作者在自己的 Windows 电脑上用 release 安装版与真实文档（PDF/DOCX/PPTX/XLSX/CSV）完成日常闭环、表格文档、接收目录与分类规则的验收，未发现问题。

### 已知限制（如实说明）

- 一万份资料库的性能数据来自 **debug** 测试配置（闭环约 5 分钟），**没有留下 release 构建的量化耗时与内存曲线**；人工验收只确认了"未发现卡顿或异常"。
- 原生文件对话框交互（文件选择器、首次向导、导入按钮）由人工验收覆盖，**没有自动化**；仓库内 `npm run test:native-smoke` 只覆盖不注入输入的真实窗口 + IPC 子集（9 步），且该冒烟偶发驱动启动失败（重跑即过）。
- 接收目录监视是周期轮询（约 2 秒）而不是文件系统事件；失败项有 60 秒冷却，用户主动点"扫描"会立即重试。
- 一至两个字符的搜索只匹配标题、描述与元数据，不匹配正文（FTS5 trigram 的取舍）。
- 残留清理失败或孤儿副本隔离时，界面不会提示，诊断只落在磁盘上的说明文件里。
- 代码审查仍有少量待办：CSV 校验的二次整表复制、解析产物的记账口径、固定压缩比阈值可能误拒高度重复的正常文档。

设计与验收文档见仓库 `docs/`（`docs/acceptance/` 含状态报告、一万份资料库报告、原生冒烟与代码审查记录，`docs/adr/` 含架构决策）。
