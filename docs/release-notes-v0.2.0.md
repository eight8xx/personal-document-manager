# v0.2.0 发布说明

2026-10-04。新增窗口布局调整与 GitHub 更新检查。提供 Windows x64 安装包与便携程序。

## 新增

- 拖动两条分隔线调整集合栏、文档列表与文档详情的宽度；保存布局比例，并随主窗口缩放。
- 支持方向键微调，以及双击或 Home 恢复默认布局。
- 设置、编辑和确认等弹窗可调整宽高；文档预览和导入进度可调整高度。
- 启动时及每 24 小时检查 GitHub 正式发布，发现新版后询问是否下载；设置中提供手动检查入口。
- 更新检查按版本号比较，忽略草稿、预发布和较旧版本；网络失败可重试。

## 使用

GitHub Release 附件中的 `personal-document-manager-Setup-0.2.0.exe` 为安装包，`personal-document-manager-Portable.exe` 为便携程序，`SHA256SUMS.txt` 为 SHA-256 校验文件。本地 `release/` 的程序使用中文产品名，与发布附件内容一致。运行新版前先关闭旧应用。

选择「下载更新」会在浏览器打开官方安装包下载；下载后需自行安装。便携版需从发布页面下载便携程序并替换旧程序。

功能验证见 [窗口布局与应用更新验收](acceptance/window-layout-updates.md)。
