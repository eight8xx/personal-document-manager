# 领域文档

工程技能探索代码库前，应按以下规则读取领域资料。

## 探索前读取

- 根目录的 `CONTEXT.md`，或存在时的 `CONTEXT-MAP.md`
- `docs/adr/` 中与当前工作相关的架构决策
- 文件不存在时静默继续，不主动要求提前创建

## 当前布局

本项目使用单上下文布局：

- `CONTEXT.md`：项目统一的领域术语
- `docs/adr/`：架构决策记录

## 使用词汇

任务标题、设计建议、假设和测试名称应使用 `CONTEXT.md` 中定义的术语。需要的新概念尚未记录时，交由 `/grill-with-docs` 补充。

## 架构决策冲突

如果新工作与已有 ADR 冲突，必须明确指出冲突，不得静默覆盖。
