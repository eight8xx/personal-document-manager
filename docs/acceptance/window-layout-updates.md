# 窗口布局与应用更新验收（2026-10-04）

主窗口仍使用现有 860×600 的最小尺寸。

## 行为

- 两条分隔线可调整集合栏、文档列表、详情栏的宽度，保存比例，并跟随主窗口变化。最小宽度分别为 160、280、220 CSS 像素。
- 支持指针拖动、左右方向键、双击与 Home 恢复默认布局。在桌面允许的窗口尺寸内保留三栏。
- 设置与编辑、确认等弹窗支持拖动右下角调整宽高。调整后的像素尺寸转换为视口比例，并受视口最大尺寸限制。
- 文档预览与导入进度支持调整高度，主窗口变化后跟随高度比例。
- 启动及每 24 小时检查 `eight8xx/personal-document-manager` 的 GitHub 正式 Release。按 SemVer 比较版本，忽略草稿、预发布和较旧版本。
- 发现新版后询问是否下载。稍后处理会略过本次运行中相同版本的自动提示；设置中的手动检查仍可再次提示。
- 确认后在浏览器打开官方安装包下载；缺少安装包时打开发布页面。下载后需关闭应用并自行安装，或替换便携程序。没有应用内自动安装、自动重启。
- 网络或 GitHub 限流错误可在设置中查看并重试，自动检查失败不遮挡工作区。
