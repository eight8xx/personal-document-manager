# 本地安全的 Office 版式预览

DOCX 和 PPTX 使用随应用发布的本地渲染器呈现只读版式预览，不依赖 Microsoft Office、LibreOffice 或网络服务。DOCX 采用 `docx-preview`，PPTX 采用 `@file-viewer/pptx`；两者按内容哈希缓存派生结果。缩略图保存在资料库内，完整渲染页保存在可清理的临时缓存中。

预览采用近似版式，不承诺与外部办公软件像素级一致。复杂对象按对象或页面降级，单页失败不影响整份文档；渲染器整体失败时回退到元数据、可提取正文和外部打开。

安全预览适用于所有文档类型：不执行宏、脚本或嵌入对象，不加载远程资源，不自动播放媒体，不修改资料库副本或源文件。只有用户明确点击超链接后，应用才把目标交给系统浏览器。加密文档和无法安全解析的内容明确报错。
